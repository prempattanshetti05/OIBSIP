# OASIS INFOBYTE Java Development Internship

This repository contains the Java development tasks completed as part of my **Oasis Infobyte (OIBSIP) Java Development Internship**.

The projects demonstrate my understanding of Java programming, object-oriented concepts, database connectivity, and web application development.

## Projects

### Task 2: Number Guessing Game

**Technology:** Java

A simple Java-based number guessing game in which the user attempts to guess a randomly generated number.

**Features**
- Generates a random number for the user to guess.
- Accepts user input.
- Provides feedback to help the user guess correctly.
- Demonstrates basic Java programming and conditional logic.

**Project folder:** `Java-Task2-NumberGuessingGame/`

[View Task 2 Source Code](./Java-Task2-NumberGuessingGame/)

### Task 5: Digital Library Management System

**Technologies:** Java, JSP, Servlets, JDBC, MySQL, Maven, Apache Tomcat

A web-based library management application designed to manage books, users, borrowing activities, returns, reservations, and fines.

**Features**
- User registration and login.
- Admin authentication and dashboard.
- Add, edit, delete, and manage books.
- Search and browse the book catalogue.
- Book issue and return request management.
- Book reservations.
- Member management and fine tracking.
- MySQL database integration.

**Project folder:** `Java-Task5-DigitalLibraryManagementSystem/`

[View Task 5 Source Code](./Java-Task5-DigitalLibraryManagementSystem/)
