# Number Guessing Game

## OASIS INFOBYTE - Java Development Internship

### Task 2: Number Guessing Game

A Java Swing based Number Guessing Game developed as part of the OASIS INFOBYTE Java Development Internship.

## Features

- Modern Java Swing graphical user interface
- Random number generation
- Easy, Medium and Hard difficulty levels
- Attempt counter
- Attempt indicator
- Too High and Too Low hints
- Score tracking
- Multiple rounds
- Win and Game Over screens
- Input validation
- Enter key support
- Interactive buttons with hover effects

## Difficulty Levels

| Difficulty | Number Range | Maximum Attempts |
|------------|--------------|------------------|
| Easy | 1 - 50 | 10 |
| Medium | 1 - 100 | 7 |
| Hard | 1 - 200 | 5 |

## Technologies Used

- Java
- Java Swing
- Java AWT
- VS Code
- Git
- GitHub
